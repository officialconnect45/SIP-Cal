# Calc Wealth — SIP Investment Calculator

Enterprise-style SIP / lump-sum investment calculator built with Next.js (frontend only).

## Features

- Premium navbar and multi-column footer
- SIP vs Lump Sum modes
- Monthly investment, expected return, duration, and annual step-up
- Live projected wealth, invested amount, and estimated returns
- Responsive layout inspired by institutional banking calculators

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build
- `npm run start` — serve production build
